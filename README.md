# ATB Client Hub

A full-stack client management portal built for ATB Visuals to manage
projects, communication, files and deliveries in one place.

## 🚀 Live Demo

https://atb-client-hub.vercel.app

## ✨ Features

- 🔐 Client & admin authentication
- 📊 Project management dashboard
- 💬 Project-based messaging
- 📁 File uploads and downloads
- 🔔 Web push notifications
- 📱 PWA support
- 👨‍💻 Admin dashboard
- 📈 Activity tracking
- 📱 Responsive mobile-first UI

## 🛠️ Tech Stack

- Next.js 16
- TypeScript
- React
- Tailwind CSS
- MongoDB + Mongoose
- NextAuth.js
- Cloudinary
- Web Push
- Framer Motion
- Vercel

## 🏗️ Architecture

The application uses Next.js App Router with API routes,
MongoDB for persistent data, NextAuth for authentication,
Cloudinary for file storage and Web Push for notifications.

The application has separate client and admin interfaces
with role-based access control.

## 🔄 Project Workflow

Client → Project → Files → Messages → Review → Delivery

## 🔐 Security

- JWT-based authentication
- Role-based access control
- Protected API routes
- Environment-based secrets
- Server-side Cloudinary credentials
- Protected admin routes
